BODRIOSAFÍO LAUNCHER WINDOWS 0.1.5 · PREPARACIÓN CON NATIVOS

Necesita tu copia legítima instalada de Minecraft Bedrock para Windows x64.
No incluye Minecraft ni reemplaza su licencia.

REQUISITO
Nether ampliado y Anticombustión nativa forman parte del launcher completo.
No se ofrece un modo alternativo sin esos módulos.

PERFIL NATIVO DISPONIBLE
Minecraft 1.26.60.5, correspondiente al binario estudiado anteriormente.
Su ejecución real dentro del juego sigue necesitando prueba.
La adaptación de nativos para 26.62/26.63 está pendiente del binario exacto.
Reconocer esos números de versión no significa que los módulos ya funcionen.

USO
Actualizar addon importa los packs BP 0.3.15 / RP 1.5.15.
Jugar prepara los dos módulos solo con una compilación que tenga perfil nativo.
Si la versión no tiene perfil, la preparación muestra un error explícito;
no se cambia a modo addon ni se anuncian los módulos como preparados.
Si Minecraft ya se abrió, no se fuerza su cierre ni se entra a un mundo.

ACTUALIZACIONES
El canal es alanbustamorag-source/panconqueso. El repositorio continúa privado;
no hay descargas automáticas anónimas mientras no exista un destino público.
Las aplicaciones no incluyen tokens de GitHub ni claves de firma.
